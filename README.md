\# HeadsetMonitor G435



A lightweight Windows application for monitoring the battery level of Logitech G435 wireless headsets.



\## Features



\- Displays the current battery percentage.

\- Designed specifically for Logitech G435.

\- Simple and lightweight interface.

\- Battery monitoring through the USB wireless receiver.



\## Requirements



\- Windows 10 / Windows 11 (64-bit).

\- Logitech G435 wireless headset.

\- USB LIGHTSPEED receiver.



\## Installation



1\. Download the latest `HeadsetMonitor\_Setup.exe` from \[GitHub Releases](https://github.com/barbulekovv/HeadsetMonitor-G435/releases).

2\. Run the installer.

3\. Follow the installation instructions.



\## Building from source



Requirements:

\- .NET 10 SDK

\- Windows

\- Visual Studio 2022 or another compatible development environment



Clone the repository:



```powershell

git clone https://github.com/barbulekovv/HeadsetMonitor-G435.git

```



Open the project and build it:



```powershell

dotnet build .\\HeadsetMonitor.csproj -c Release

```



\## Compatibility



Currently developed and tested for Logitech G435. Other headset models are not officially supported.
